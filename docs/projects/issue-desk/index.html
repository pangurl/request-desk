02 / Issue Desk

GitHub 问题受理台

同步公开 GitHub 仓库的 Issue，在列表与详情间快速查看上下文、标记处理决定。

打开演示 ↗Evidence Scout 上游源码

体验流程

  1. 载入示例或输入公开仓库并同步
  2. 筛选标签或远端状态
  3. 打开详情并保存受理决定
  4. 查看同步记录和失败原因

实现方式

React、GitHub REST API、浏览器持久化。受理决定和 GitHub 原始状态分别保存，重复同步按 Issue ID 合并。示例数据来自 Evidence Scout。
